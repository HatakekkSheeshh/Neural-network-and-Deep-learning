# DSA & ANN C++ Library

## Overview

This repository is a C++ library that supports fundamental data structures, graph algorithms, tensor operations, and especially the construction and training of simple artificial neural network (ANN) models for classification tasks. The library is designed for educational purposes, helping users practice and understand concepts in data structures, algorithms, and machine learning.

## Key Features

- **Basic Data Structures:** Linked lists, dynamic arrays, binary trees, hash maps, stacks, queues, etc.
- **Graph Algorithms:** Supports both directed and undirected graphs, with algorithms such as Dijkstra, Topological Sort, and more.
- **Tensor Operations:** Provides basic and advanced tensor operations.
- **Artificial Neural Networks (ANN):**
  - Build MLP models for 2-class and 3-class classification.
  - Supported layers: Fully Connected, ReLU, Softmax, Sigmoid, Tanh.
  - Loss functions: CrossEntropy, etc.
  - Optimizers: SGD, Adam, Adagrad, etc.
  - Model checkpoint saving/loading.
- **DataLoader:** Batch data loading for training and evaluation.
- **Flexible configuration via `config.txt`**
